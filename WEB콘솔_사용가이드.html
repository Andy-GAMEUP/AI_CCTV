매장·장치를 콘솔에 등록하는 방법

확인된 양식과 미검증 후속 단계를 표시했습니다.

최초 등록 · 매장 → 장치 → 구역 → 연결·분석 확인

실제 입력 양식을 확인했지만 저장 이후 단계는 미검증입니다. 납품 정보와 권한을 확인한 후 담당자가 등록하세요. 공식 설명으로 보완된 절차는 14단계, API 준비는 15단계에 정리했습니다.

  1. 매장과 영업시간을 만듭니다.Workbench → System configuration → System management → Stores architecture → Add a store

    전체 메뉴 화면에서는 상단 System Management로 이동합니다. 생성 양식 단계: Create a store → Associated device → Create in-store zone.

    필수 표시: Belonging region, Store name, Store number, Address, Detailed address, Business status, Launch time, Store area(m²). 영업시간은 Repeat every day / Repeat every week로 나뉩니다. 확인 시 양식 기본 시간 10:00~22:00는 실제 영업시간으로 수정해야 합니다. 한국 주소 지도와 시간대는 공급사 확인 대상입니다.

    Save&Next / Skip the next steps and save directly 버튼을 확인했습니다. 저장 후 장치·구역 연결 화면은 공급사 매뉴얼과 대조하세요.

  2. 모델별 등록 유형과 key를 확인합니다.Device management → Device Config → Add device

    필수 표시: Serial number, Device name, Device type, Associated store. 추가 항목: key, Associated in-store zone, Inherit store access rights(확인 시 체크됨). key는 필수 표시가 없지만 모델별 필요 여부·발급 위치는 미확인입니다. 매장 선택 전 구역은 비활성 상태였습니다.

    유형: Video device / Traffic(in) device / Traffic(pass) device / Storage device / Attention device / Traffic(in&pass) device. DX-1100 유형 및 카메라 별도 등록 여부는 공급사에서 확정받으세요. 명칭만 보고 Storage device를 임의 선택하지 않습니다. 기존 바인딩을 확인하고, 매장 접근자가 장치 권한도 상속할지 선택한 후 Confirm으로 저장하는 절차입니다.

  3. 온라인 상태와 카메라 3개 채널을 확인합니다.Device management → Device Config / Channel Management

    목록 항목: Device model·Device type·Status·Device binding time·Firmware version·Last online time 등. 매장·유형·상태·Visible 필터가 장치를 숨기지 않는지 확인합니다. 등록 후 셋탑과 3대 카메라의 실제 채널 연결 구조·온라인 상태·영상을 검증해야 합니다.

  4. 분석 구역과 카메라를 매핑합니다.

    Create in-store zone 단계와 Associated in-store zone 항목은 확인했습니다. 실제 도면 업로드·축척·층/구역·카메라 매핑 화면은 현재 빈 매장이라 검증 전입니다. 샘플 매장과 단계별 자료를 받으세요.

영상·방문객·동선·보고서 사용 순서

실제 영문 메뉴를 병기해 화면에서 찾기 쉽도록 했습니다.

매일 사용하는 조회 순서

  1. 영상과 장치 상태부터 확인합니다.Video surveillance → 매장/채널 선택 → 실시간 영상

    Store / Region / Favorite / Tag, Online 필터와 검색을 확인했습니다. 등록 후 3채널 영상과 지정 시각의 녹화를 확인합니다. Stop all·Capture all·Asynchronous playback·Double speed·PTZ·Layout·Full screen·Dowload recordings UI가 있습니다. 공식 문서의 배속·캡처·배치·다운로드 조작법은 14단계에 반영했습니다. 실제 장비 재생·다운로드·모델별 PTZ/플러그인은 미검증입니다.

  2. 기간·매장을 선택해 방문객을 조회합니다.Accurate traffic → Real-time traffic / Traffic analysis → Overview of in-store traffic

    Real-time traffic의 Today / Yesterday / This week / This month / Customize, Venue, Comparison period(MoM), Data mode(Distribution), Search를 확인했습니다. 같은 기간·매장·필터로 비교하세요. 비교 용어와 Distribution의 정확한 정의는 공급사 확인 대상입니다.

  3. 동선·히트맵을 별도로 조회합니다.Accurate traffic → Customer Mapping → Moving line analysis / Density heat map / Store area map

    날짜·매장 선택 후 Search를 누릅니다. 동선은 전체/구역별 방향·경로·구역 공유 흐름을 구분합니다. 히트맵에는 Zone traffic statistics / Avg. attention duration과 3D / Table / Chart UI가 있습니다. 실제 도면·범례·수치는 샘플 데이터로 검증해야 합니다.

  4. 지표를 선택하고 미리보기 후 내보냅니다.Accurate traffic → Export data → Export configuration → 조건·지표 선택 → Preview → Export

    조건: Time selection, Time dimension, Venue dimension, Venue selection, Indicator selection. 지표 그룹: Traffic / Sales / Fitting / Customer group / Other. 파일 형식·인코딩·행 제한·수치 일치는 미검증입니다. 동일 조건의 화면 합계와 파일 합계를 대조하세요.

  5. 데이터 없음은 원인별로 점검합니다.

    매장/장치 존재 → 조회 필터·권한 → 온라인·채널 → 분석 지원/활성화 → 구역 연결 → 영업시간/시간대 → 집계 지연 순으로 확인합니다. Device warning에는 Warning statistics·Alarm push, Device statistics에는 Device information·오프라인 비율/상세·매장별 장치 통계·Offline log of device가 있습니다. 메뉴를 확인했으며 실제 장애 로그는 검증 전입니다.

14

공식 WEB 매뉴얼로 정리한 사용가이드

이미 설명된 조작법은 재요청하지 않고, 실제 환경에서의 검수만 남깁니다.

공급사 WEB 문서를 반영한 사용 순서공식 WEB 가이드 ↗ · 기존 10~12단계는 실제 로그인 UI 점검, 이 절은 공급사 문서 근거입니다. 중국어 문서와 현재 영문 UI의 메뉴 구조가 달라 기능 목적을 기준으로 찾으세요. 모든 하위 문서를 완역한 것이 아니라 설치·주요 사용 업무에 관련된 11개 본문을 검토했습니다. 문서에 있는 기능도 이번 장치·권한·라이선스에서 실제 지원하는지는 별도 검수합니다.

01 · 매장·장치·분구 준비

  1. System Management → Stores architecture에서 조직·매장을 구성합니다.

    지역 구조 아래 매장을 만들고 기업 내 고유 Store number를 부여합니다. Address는 지도 좌표·날씨·현장 순찰 위치, Detailed address는 층·호수에 해당합니다. 상태는 운영/중지/폐쇄이며 실제 영업시간이 통계 범위의 기준입니다. 한국 지도 입력·자정 넘김·시간대는 공급사 미결 사항입니다.

  2. 내부 분구를 만들고 장치를 연결합니다.

    분구는 장치 구역 관리와 구역별 집계에 사용됩니다. 실제 도면 업로드·축척·다중 카메라 보정은 별도 안내가 필요합니다. Device Config에서 본체/포장 라벨의 SN과 실제 기능에 맞는 유형·매장을 선택합니다. DX-1100 등록 유형과 key 조건은 아직 미확정입니다.

  3. 권한 상속과 목록 필터를 확인합니다.

    Inherit store access rights를 체크하면 해당 매장 접근자가 장치 접근권한도 상속합니다. 해제하면 이 방식의 권한 부여가 되지 않으므로 기존의 별도 권한까지 삭제되는 것으로 해석하지 마세요. 장치 목록은 매장 권한 범위 내 결과이며 이름/SN·유형·온라인·운영상태·Visible 필터를 확인합니다. API의 display=true/false는 가시성을 뜻합니다.

근거: 매장 구조 ↗ · 장치 목록 ↗ · 장치 API ↗. 화면에서 실제 저장·권한 변경은 수행하지 않았습니다.

02 · 실시간 영상 → 녹화 재생 → 필요한 구간 저장

  1. Video surveillance에서 권한이 있는 매장·채널을 선택합니다.

    매장명·조직·즐겨찾기·태그로 찾습니다. Favorite store는 즐겨찾기, Store traffic은 당일 방문객 추이, Stop all은 열린 영상 종료입니다.

  2. 녹화 시각을 정하고 동기/비동기 재생을 선택합니다.

    동기 재생은 현재 선택 창의 재생 시각을 여러 창에 적용합니다. 비동기는 각 창을 독립 제어합니다. 공식 가이드의 배속은 1×~8×, Layout은 1/4/9화면입니다. PTZ는 지원 카메라에서만 사용합니다. Full screen은 ESC로 종료합니다.

  3. 스냅샷 또는 녹화 구간을 저장합니다.

    Capture all은 현재 재생 중인 화면을 캡처하며 우측에서 확인·다운로드할 수 있습니다. 녹화 다운로드는 재생 시작 시각부터 1/5/10/30분 구간을 선택하는 방식입니다. 방문객/POS가 연계되면 타임라인에 사건 시각을 표시할 수 있습니다. 실제 녹화 존재·다운로드 권한·파일 재생은 E05에서 검수합니다.

근거: 영상 감시 공식 사용법 ↗. 지원 브라우저/플러그인·모델별 지원은 A02/A05에 남깁니다.

03 · 방문객·체류·동선·히트맵 조회
