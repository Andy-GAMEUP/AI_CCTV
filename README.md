# AI CCTV · DX-1100 설치·온라인 콘솔 사용 가이드

돔형 IP CCTV 최소 3대와 DX-1100을 사용하는 AI 방문객 분석 솔루션의 설치·준비·온라인 콘솔 사용 및 공급사 검수 자료입니다.

## 주요 문서

- [설치·온라인 콘솔 통합 매뉴얼](AI_CCTV_설치_매뉴얼.html): 준비물, CCTV 고정, HDD, 공유기·PoE·노트북 배선, IP, DX 설정, 콘솔 등록·조회·동선·보고서.
- [공급사 회신용 HTML 체크리스트](DX-1100_공급사_설치_콘솔_체크리스트.html): 37개 항목의 회신 상태·근거·담당자·기한, CSV 다운로드와 인쇄.
- [체크리스트 Markdown](DX-1100_공급사_설치_콘솔_체크리스트.md): 메일에 복사하거나 수정하기 위한 원문.
- [초기 보강 요청서](DX-1100_공급사_가이드_보강요청.md): 온라인 콘솔 점검 전 작성한 설치 자료 요청 초안.

HTML은 저장소를 다운로드한 뒤 파일을 브라우저에서 열면 됩니다. GitHub 파일 화면에서는 HTML 소스가 표시됩니다. 별도 웹사이트 배포는 포함하지 않습니다.

HTML의 이미지·스타일·스크립트는 문서 안에 포함되어 있어 오프라인 열람이 가능합니다. 원본 PDF와 체크리스트 링크를 사용하려면 파일의 상대 위치를 유지하세요. 실제 온라인 콘솔에는 인터넷과 별도 로그인 권한이 필요합니다.

## 확인 범위

- 기준일: 2026-10-31.
- 셋탑: 사용자 확인 DX-1100. 세부 형번·펌웨어·실제 카메라 조합은 공급사 확인 대상입니다.
- [YUNDVISION 콘솔](https://yd.yunding360.com/V1/work)의 로그인된 Chrome 화면에서 메뉴·일부 조회 화면·등록 양식을 확인했습니다.
- 점검 계정에서 조회 가능한 장치 0대, 매장 목록 데이터 없음, 영상 0/0 상태였습니다. 원인은 미확정입니다.
- 실제 등록·운영 설정 저장·권한 변경은 수행하지 않았습니다. 실제 영상 재생·분석 정확도·플랫폼 데이터 내보내기는 미검증입니다.
- 체크리스트는 공급사에 발송하지 않은 검토용 문서입니다.

## 체크리스트 작성·회신

입력은 현재 브라우저의 로컬 저장소에만 저장됩니다. 입력 내용이 HTML 파일 자체에 기록되지는 않습니다. 작성 후 CSV 다운로드 또는 인쇄/PDF 결과로 회신하세요. 비밀번호·시리얼 key는 문서에 기록하지 말고 별도 안전한 경로로 인계합니다.

## HTML 다시 만들기

Python 3.10 이상을 권장합니다.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python build_manual.py
```

- `build_manual.py`: PDF 기반 설치 매뉴얼과 최종 문서 생성.
- `console_manual.py`: 실제 확인한 콘솔 설명과 37개 체크리스트 데이터·회신 문서 생성.
- `console_assets/`: 문서에 사용하는 콘솔 화면과 매뉴얼 미리보기. 조직명이 노출되는 내부 영상 화면은 업로드에서 제외합니다.
- `tmp/`: PDF 렌더링 임시 파일. 없으면 원본 PDF에서 다시 생성되며 Git에 포함하지 않습니다.
