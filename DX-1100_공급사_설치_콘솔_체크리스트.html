DX-1100 + 돔형 CCTV 최소 3대 + 공유기·PoE 스위치 + 1TB 권장 저장장치를 기준으로 요청드립니다. 제공된 공식 WEB/API 문서로 확인된 설명은 재요청에서 제외했습니다. 남은 질문만 현재 납품 형번·펌웨어에 맞춰 회신해 주세요.

현재 확인 상태 · 2026-10-31로그인 콘솔에서 조회 가능한 장치 0대, 매장 목록 없음, 영상 0/0, 분석 데이터 없음입니다. 원인은 미확정입니다. 메뉴·양식을 확인했으며 실제 등록·저장·영상·분석·내보내기 동작은 검증 전입니다.

P0: 설치/운영/검수 전 필수. P1: 운영 기능·추가 범위 확인. F01~F05는 API 연동을 선택할 때만 적용합니다. 미지원·해당 없음도 사유와 대안을 회신해 주세요. 왼쪽 검수 완료 체크는 발주자가 증거와 실제 결과를 확인한 후 표시합니다. 공급사의 ‘제공 완료’가 자동 검수 합격을 의미하지 않습니다.

작성·전달 방법입력은 이 브라우저에만 저장됩니다. HTML 파일 자체에는 입력 결과가 기록되지 않습니다. 작성 후 ‘회신 CSV 다운로드’ 또는 ‘인쇄 / PDF 저장’ 결과를 회신해 주세요. 긴 설명은 별도 첨부하고 근거 칸에는 파일명·쪽을 적습니다. 비밀번호·장치 key는 별도 안전한 경로로 인계합니다.

입력 내용은 현재 브라우저에 저장됩니다.
